# Interface

Use a standard Mac utility window with system typography, system colors, native buttons and a toolbar. Respect light and dark appearance. The wallpapers themselves supply the imagery. No decorative animation or custom navigation.

The window has a downloaded wallpaper gallery and a daily schedule list. Selecting a wallpaper reveals a time picker, Add to Schedule, and Apply Now. Show download instructions and recoverable errors in plain language. Closing the window quits settings completely; macOS keeps the schedule without a menu bar process. The footer explains this explicitly. Open the Applications copy when settings are needed.

Use a native menu dropdown to select Fixed Time or a daylight phase, both below the gallery and on each schedule entry. Fixed Time shows a time field; solar selections show today's resolved time and a definition. A Daylight Location popover offers a current-location button and manual coordinates. Never prompt for location before the user chooses that button.

App icon: use Assets/AppIcon.png, the approved coastal-photo and circular-type artwork, unchanged. scripts/build-icon.sh packages it into standard macOS ICNS sizes. The built-in image-generation prompt is retained in Assets/AppIcon.prompt.txt.
